# Guardian 0.6.15

This release restores radio selection by name in Station settings.

- Choose common supported Hamlib radios from a drop-down list.
- Browse the complete model list reported by the installed Hamlib build.
- Store the required Hamlib model number internally; operators no longer type
  or need to know numeric model IDs.
- Preserve previously configured radios, including models outside the curated
  common-radio list.

This release is based on 0.6.14 and does not include further VARA connection
changes.
